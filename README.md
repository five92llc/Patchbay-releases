# PatchB@y: installers and release notes

PatchB@y is a virtual audio mixer for macOS (Apple silicon, macOS 14.4 or later).

* **Download:** https://patchbay.five92.dev/download (always the newest installer), or the [latest release](../../releases/latest) here.
* **Release notes:** https://patchbay.five92.dev/releases/
* **Manual:** https://patchbay.five92.dev/manual/
* **Help or licence questions:** the contact form at https://patchbay.five92.dev/#contact

This repository only hosts the installers. PatchB@y is proprietary software; see `LICENSE`.
